ClimaGuard

Sistema de alerta preventiva por baja iluminación

Una propuesta tecnológica para detectar períodos de baja iluminación y proporcionar una señal de alerta al personal.

⚠️ El reto

En un espacio recreativo pueden presentarse cambios en las condiciones ambientales que reduzcan considerablemente la iluminación. ClimaGuard busca proporcionar una alerta al personal cuando se detecta poca luz durante un determinado período de tiempo.

💡 Nuestra solución

ClimaGuard es un sistema que detecta cuando el nivel de luz permanece bajo durante cierto tiempo. Al cumplirse esta condición, se activa una señal visual mediante LEDs y el sistema cuenta con un buzzer destinado a generar una alerta sonora.

☀️ Luz normal Condiciones habituales
🌥️ Poca luz Disminuye la iluminación
🔎 Detección La LDR detecta el nivel de luz
💡 Alerta visual Se activan los LEDs
🔊 Alerta sonora Mediante el buzzer

⚙️ ¿Cómo funciona?

  1. La LDR o fotorresistencia detecta el nivel de iluminación.
  2. El Arduino Uno recibe la información proveniente del sensor.
  3. Cuando se presenta una condición de baja iluminación, el sistema activa la señal de alerta.
  4. Los LEDs funcionan como indicadores visuales del estado del sistema.
  5. El buzzer está destinado a proporcionar una señal sonora de alerta.
  6. El pulsador forma parte del circuito de control del prototipo.
