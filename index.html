01 · Contexto

El reto

En un espacio recreativo como IRTRA Petapa, las condiciones ambientales pueden cambiar durante el desarrollo de las actividades. Una disminución prolongada de la iluminación puede ser una señal para prestar mayor atención a las condiciones del entorno.

A partir de esta necesidad se planteó desarrollar una solución tecnológica capaz de detectar una disminución significativa de luz y generar una señal de alerta.

El objetivo de ClimaGuard es apoyar la prevención mediante una detección sencilla, visual y automatizada.
02 · Propuesta

Nuestra solución

ClimaGuard utiliza un sensor de luz para identificar cuándo existe poca iluminación durante un período prolongado.

Cuando se alcanza la condición establecida en el sistema, Arduino procesa la información y activa una señal visual. También se planteó una alerta sonora como parte del sistema.

04 · Tecnología

¿Cómo funciona?

1. Detección de luz

La fotorresistencia o LDR responde a la cantidad de iluminación presente en el entorno.

2. Procesamiento

Arduino recibe la información del sensor y determina si se cumple la condición de baja iluminación.

3. Alerta visual

Cuando se detecta la condición establecida, el sistema activa una señal luminosa mediante los LEDs.

4. Alerta sonora

El proyecto contempla una señal sonora mediante un buzzer. Esta parte todavía se encuentra en desarrollo.

Ciudades y comunidades sostenibles
