ClimaGuard

Sistema de alerta preventiva por baja iluminación

Una propuesta tecnológica para detectar períodos de baja iluminación y proporcionar una señal de alerta al personal.

⚠️ El reto

En un espacio recreativo pueden presentarse cambios en las condiciones ambientales que reduzcan considerablemente la iluminación. ClimaGuard busca proporcionar una alerta al personal cuando se detecta poca luz durante un determinado período de tiempo.

💡 Nuestra solución

ClimaGuard es un sistema que detecta cuando el nivel de luz permanece bajo durante cierto tiempo. Al cumplirse esta condición, se activa una luz de alerta en el tablero y el sistema está diseñado para generar también una señal sonora.

⚙️ ¿Cómo funciona?

  1. El sistema detecta el nivel de iluminación.
  2. Comprueba que la condición de poca luz permanezca durante un tiempo determinado.
  3. Se activa la luz de alerta en el tablero.
  4. La alerta sonora se encuentra en proceso de implementación.
  5. El aviso permite al personal estar atento y tomar las precauciones correspondientes.
